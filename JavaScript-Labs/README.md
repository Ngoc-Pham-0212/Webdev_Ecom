# JavaScript Labs (Lab 08 – Lab 10)

Tổng hợp các bài thực hành lập trình JavaScript phía máy khách thuộc học phần **Phát triển Ứng dụng Thương mại Điện tử** (`Webdev_Ecom`), biên soạn dựa trên giáo trình *Fundamentals of Web Development, 2nd Edition*.

- **Sinh viên thực hiện:** Ngoc-Pham-0212
- **Trang tổng hợp (GitHub Pages):** [https://ngoc-pham-0212.github.io/Webdev_Ecom/JavaScript-Labs/](https://ngoc-pham-0212.github.io/Webdev_Ecom/JavaScript-Labs/)

## Danh sách các bài Lab

| Bài Lab | Chủ đề | Nội dung trọng tâm | Liên kết Demo |
| :--- | :--- | :--- | :--- |
| **[Lab 08](./Lab%2008/)** | JavaScript 1 – Language Foundations | Biến, câu lệnh điều kiện, vòng lặp, mảng, đối tượng, mảng đối tượng và hàm. | [Mở Lab 08](https://ngoc-pham-0212.github.io/Webdev_Ecom/JavaScript-Labs/Lab%2008/) |
| **[Lab 09](./Lab%2009/)** | JavaScript 2 – DOM and Events | Truy xuất & thao tác cây DOM, xử lý sự kiện, gỡ lỗi Debugger và kiểm tra biểu mẫu. | [Mở Lab 09](https://ngoc-pham-0212.github.io/Webdev_Ecom/JavaScript-Labs/Lab%2009/) |
| **[Lab 10](./Lab%2010/)** | JavaScript 3 – jQuery | Bộ chọn jQuery, sự kiện, thao tác DOM, hiệu ứng động và gửi yêu cầu AJAX / `jqXHR`. | [Mở Lab 10](https://ngoc-pham-0212.github.io/Webdev_Ecom/JavaScript-Labs/Lab%2010/) |
