1. Responsive Web Design với CSS @media & Thẻ <picture>

Bài tập: Bai1.html

Nội dung thực hành xây dựng bố cục thích ứng (Responsive Layout) trên nhiều kích thước màn hình và thiết bị khác nhau:

  • Breakpoint Tablet / Mobile (max-width: 768px): Chuyển bố cục 2 cột .left và .right thành width: 100% để hiển thị xếp chồng.
  • Breakpoint Màn hình nhỏ (321px – 479px): Ẩn thành phần .right bằng thuộc tính display: none.
  • Chế độ In ấn (@media only print): Ẩn khối .left và mở rộng khối .right ra toàn bộ chiều ngang (width: 100%) khi người dùng in trang.
  • Responsive Images với <picture>: Sử dụng các thẻ <source media="(min-width: 600px)"> và <source media="(min-width: 400px)"> kết hợp thẻ <img> dự phòng để hiển thị logo UEH / CTD phù hợp với độ rộng khung nhìn.
@media only screen and (max-width: 768px) {
    .left, .right {
        width: 100%;
    }
}
@media only screen and (max-width: 479px) and (min-width: 321px) {
    .right {
        display: none;
    }
}
@media only print {
    .left {
        display: none;
    }
    .right {
        width: 100%;
    }
}

2. Thực Hành Chrome DevTools Console & JavaScript (Game Dino)

DOM & Runtime JS

Khai thác tab Console trong trình duyệt để truy xuất và thay đổi thuộc tính/phương thức của đối tượng JavaScript đang chạy (game T-Rex Runner):

  • Truy xuất đối tượng game: Sử dụng Runner.getInstance() để lấy thực thể điều khiển trò chơi.
  • Ghi đè phương thức (Method Overriding): Gán lại this.gameOver = () => {} (Arrow Function) hoặc function () {} để vô hiệu hóa trạng thái thua cuộc khi va chạm.
  • Điều chỉnh tốc độ & vật lý nhảy (IIFE): Can thiệp trực tiếp vào các tham số setSpeed(), maxSpeed, acceleration và cấu hình tRex.config (gravity, maxJumpHeight, minJumpHeight, initialJumpVelocity).
(() => {
    const r = Runner.getInstance();

    if (!r) {
        console.log("Không tìm thấy game Dino!");
        return;
    }

    // Vô hiệu hóa Game Over
    r.gameOver = () => {};

    // Tăng tốc độ
    r.setSpeed(15);
    r.config.maxSpeed = 30;
    r.config.acceleration = 0.003;

    // Điều chỉnh độ cao nhảy
    r.tRex.config.gravity = 0.3;
    r.tRex.config.maxJumpHeight = 10;
    r.tRex.config.minJumpHeight = 10;
    r.tRex.config.initialJumpVelocity = -18;

    console.log("Đã áp dụng cấu hình Dino!");
})();
